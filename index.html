What this is

A simple dungeon timer for Realm of the Mad God, built to track how long exalting and other runs actually take — not for leaderboards, just personal stats.

How to use

  1. Pick a dungeon on Timer, hit Start when you enter, End when you finish.
  2. Use Nexus or Died if the run did not clear.
  3. After a clear, optionally log party/organic, group size, and search time.

Tabs

  • Overview — exalt summary, best/avg times, recent runs at a glance.
  • Times — full log with filters and per-dungeon averages.

Data

Runs are saved on this device. With the local server (python3 serve.py) they go to runs.json in this folder; opening the HTML file alone uses browser storage.
