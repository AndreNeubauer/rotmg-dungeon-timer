# Agent instructions (Cursor, Cloud Agent, and other bots)

## Git workflow — mandatory

**Push and merge. Never open a pull request.**

This repo does **not** use pull requests. Any agent working here must follow this workflow:

1. Commit changes.
2. Push to `origin`.
3. Merge into `main`.
4. Push `main`.

### Never do this

- Do not create pull requests (draft or otherwise).
- Do not use PR tools (`ManagePullRequest`, `gh pr create`, GitHub PR UI, etc.).
- Do not suggest or ask about opening a PR.

When in doubt: **push, merge, done.**
